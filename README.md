## Featured: SlipSnap

<a href="https://slipsnap.pages.dev/"><img src="https://raw.githubusercontent.com/tepjey/iium-schedule-converter/main/assets/og-image.png" alt="SlipSnap: an IIUM confirmation slip turned into a weekly timetable on a phone lock screen" width="640" /></a>

[**SlipSnap**](https://slipsnap.pages.dev/) turns an IIUM course registration confirmation slip into a weekly timetable or a phone lock screen wallpaper. It is free for every IIUM student, and the slip is read in the browser, so it is never uploaded.

- **Slip parser.** Reads the PDF with pdf.js and rebuilds the table from text positions. It handles the degree and foundation (CFS) layouts, wrapped titles, repeated slots, exempted courses and AM/PM that the slip prints inconsistently. Covered by snapshot tests on fake slips.
- **Timetable and wallpapers.** Themes, a Theme Studio, and presets for iPhones, Android phones and iPads. Saving works through the share sheet, including in-app browsers.
- **GPA and CGPA calculator.** Two grading scales, academic rules with their regulation references, a target planner, and integer-hundredths maths to avoid rounding errors.
- **SlipSnap Pro.** An optional RM5 one-time unlock, built on Stripe Checkout, with offline-verifiable signed keys, a revocation list, rate limiting and security headers.
- **Engineering.** React 19, Vite and Tailwind CSS 4. Cloudflare Pages and Functions. Vitest tests, linting and type checks on every push, with automatic deploys through GitHub Actions to a live site and a beta channel.
- **Support.** Student reports are read, reproduced and fixed, with the fix tested against the exact rows they sent.

The original [IIUM Schedule Converter](https://github.com/tepjey/iium-schedule-converter) address now redirects to SlipSnap.
